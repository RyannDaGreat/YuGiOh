# Third-party content in this directory

This directory is generated by `bin/bake-carddata.js` from the pinned upstream
sources that `setup.sh` fetches. It is committed so a statically hosted build
works without running `setup.sh`.

## `scripts/*.lua` — Project Ignis CardScripts

Redistributed **unmodified** from <https://github.com/ProjectIgnis/CardScripts>,
which is licensed **AGPL-3.0** (see that repository's `COPYING`). AGPL permits
redistribution; anyone distributing a modified version, or offering it over a
network, must make the corresponding source available. These files are verbatim
copies — the pinned commit is recorded in `setup.sh`.

## `cards.json` — derived from Project Ignis BabelCDB

Card names, effect text and stats, extracted for only the cards this project's
decks use, from <https://github.com/ProjectIgnis/BabelCDB>. That repository
publishes **no explicit license file**; this redistribution rests on the same
ecosystem precedent every Yu-Gi-Oh! simulator relies on. Yu-Gi-Oh! and all card
text are property of Konami; this is a non-commercial fan project.

## `strings.conf` — Project Ignis Distribution

EDOPro's system strings, from
<https://github.com/ProjectIgnis/Distribution>, pinned in `setup.sh`.

Nothing here is authored by this project. Regenerate with:

    ./setup.sh && node bin/bake-carddata.js
